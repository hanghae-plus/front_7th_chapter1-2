# 테스트 명세: 반복일정은 해당되는 모든 날짜에 아이콘과 함께 캘린더에 표시되어야한다.

## 범위

- 월/주/일 보기에서 반복 인스턴스 생성과 아이콘 표시
- exceptions 및 repeatEnd 처리
- 접근성 라벨 확인

## 테스트 케이스

1. Weekly - 월/수 반복 일정 아이콘 표시

- Given: 매주 월/수 10:00-11:00 반복 이벤트
- When: 월 보기를 연다
- Then: 해당 달 모든 월/수 날짜에 이벤트가 렌더되고 아이콘이 존재(aria-label="반복 일정")

2. Monthly - 매월 15일 아이콘 표시

- Given: 매월 15일 09:00-10:00 반복 이벤트
- When: 15일이 포함된 주 보기를 연다
- Then: 해당 주 15일 인스턴스가 보이고 아이콘 존재

3. Exceptions 제외

- Given: 위 두 이벤트에 exceptions로 특정 날짜를 지정
- When: 해당 날짜를 포함하는 뷰를 연다
- Then: 그 날짜 인스턴스는 표시되지 않는다(아이콘도 없음)

4. repeatEnd 경계

- Given: repeatEnd가 있는 weekly 이벤트
- When: repeatEnd 이전/당일/이후 범위를 각각 연다
- Then: 이전/당일은 표시, 이후는 미표시

5. 접근성

- Given: 반복 인스턴스가 표시됨
- Then: 아이콘 요소에 `aria-label="반복 일정"` 존재

6. 월 뷰 - 다음 달/주로 이동 시 미래 인스턴스와 아이콘 표시

- Given: 2025-11-05 시작, 매주(간격 1) 반복 이벤트, 종료일 2025-11-26
- When: 월간 뷰에서 다음 주/다음 달로 이동한다
- Then: 이동한 뷰의 해당 요일에 이벤트 텍스트가 표시되고 `aria-label="반복 일정"` 아이콘이 함께 표시된다

7. 주 뷰 - 다음 주로 이동 시 미래 인스턴스와 아이콘 표시

- Given: 오늘 날짜에 시작하는 매주(간격 1) 반복 이벤트를 생성
- When: 뷰를 Week로 전환하고 Next로 1주 이동한다
- Then: 다음 주 동일 요일 셀에서 이벤트 텍스트와 `aria-label="반복 일정"` 아이콘이 표시된다

## 비고

- 테스트 데이터는 msw 핸들러/로컬 목을 재사용하거나, 컴포넌트 렌더 전 주입
- 대용량 월 범위도 시간 내 완료되는지 간단한 성능 어서션은 선택
