## 📋 1. Executive Summary

### 1.1 제품 개요

반복 일정 기능은 사용자가 일정 생성 또는 수정 시 반복 유형을 선택하여 일정 시리즈를 자동으로 생성하는 기능입니다. 매일, 매주, 매월, 매년 반복 옵션을 제공하며, 복잡한 날짜 케이스(예: 월말 31일, 윤년 2월 29일)에 대한 명확한 규칙을 적용합니다.

### 1.2 비즈니스 목표

- **사용자 가치**: 반복되는 업무/약속 입력 시간 절감 및 일정 누락 방지
- **제품 가치**: 캘린더 앱 활용도 증가, 일일 활성 사용자(DAU) 향상
- **경쟁력**: 직관적이고 예측 가능한 반복 일정 생성 경험 제공

### 1.3 핵심 원칙

1. **명확성**: 존재하지 않는 날짜는 절대 대체하지 않고 스킵
2. **단순성**: 반복 일정은 일정 겹침을 고려하지 않음 (사용자 의도 우선)
3. **예측 가능성**: 사용자가 선택한 날짜/요일에 정확히 생성

## 🎯 2. 사용자 요구사항

### 2.1 사용자 스토리

**As a** 캘린더 사용자  
**I want** 일정 생성/수정 시 반복 유형을 선택하여 일정을 자동 생성할 수 있다  
**So that** 반복되는 업무/약속을 한 번의 설정으로 관리하고 시간을 절약할 수 있다

### 2.2 사용자 페인 포인트

- 반복되는 일정을 매번 수동으로 입력해야 함
- 일정 누락 위험
- 복잡한 날짜 케이스(월말, 윤년)에서 예상과 다른 동작

### 2.3 사용자 시나리오

**시나리오 1: 주간 회의 일정 생성**

- 매주 수요일 오후 2시 팀 회의를 다음 3개월간 자동 생성하고 싶음
- 입력: 시작일 2025-11-05(수), 반복 유형 매주, 종료일 2026-02-05
- 기대 결과: 매주 수요일 11회 자동 생성

**시나리오 2: 월말 정산 작업**

- 매월 마지막 날(31일이 있는 달만) 정산 작업을 설정하고 싶음
- 입력: 시작일 2025-01-31, 반복 유형 매월, 5회
- 기대 결과: 1월, 3월, 5월, 7월, 8월에만 생성 (2월, 4월, 6월, 9월은 스킵)

**시나리오 3: 생일/기념일 설정**

- 2월 29일 생일을 윤년에만 알림받고 싶음
- 입력: 시작일 2024-02-29, 반복 유형 매년, 종료일 2030-02-28
- 기대 결과: 2024년, 2028년에만 생성 (2025-2027, 2029년은 스킵)

## ⚙️ 3. 기능 요구사항 (v1.0 범위)

### 3.1 포함 범위 (In Scope)

#### FR-1: 반복 유형 선택

- **설명**: 사용자가 일정 생성/수정 폼에서 반복 유형을 선택할 수 있음
- **옵션**:
  - 매일 (Daily)
  - 매주 (Weekly)
  - 매월 (Monthly)
  - 매년 (Yearly)
- **우선순위**: P0 (필수)

#### FR-2: 반복 종료 조건 설정

- **설명**: 반복 일정의 종료 시점을 지정
- **옵션**:
  - 횟수 기반 (count): 총 N회 생성
  - 날짜 기반 (until): 특정 날짜까지 생성
- **제약사항**: count와 until 중 하나만 선택 가능 (상호 배타적)
- **우선순위**: P0 (필수)

#### FR-3: 반복 간격 설정

- **설명**: 반복 주기의 간격을 지정 (고급 옵션)
- **범위**: 1-12 (기본값: 1)
- **예시**: interval=2이면 "2일마다", "2주마다", "2개월마다", "2년마다"
- **우선순위**: P1 (중요)

#### FR-4: 날짜 대체 없음 (No Date Substitution)

- **설명**: 존재하지 않는 날짜는 절대 대체하지 않고 건너뜀
- **특수 케이스**:
  - **31일 시작 + 매월**: 31일이 있는 달에만 생성 (28일/29일/30일인 달은 스킵)
  - **30일 시작 + 매월**: 30일이 없는 2월은 스킵
  - **2월 29일 시작 + 매년**: 윤년에만 생성 (평년은 스킵, 2/28 또는 3/1로 대체하지 않음)
- **우선순위**: P0 (필수, 명확성 확보)

#### FR-5: 반복 일정 겹침 무시

- **설명**: 반복 일정 생성 시 기존 일정과의 시간 겹침을 검사하지 않음
- **이유**: 사용자가 명시적으로 반복을 설정했으므로 의도된 겹침일 수 있음
- **동작**: 겹침 경고/차단 없이 모든 인스턴스 생성
- **우선순위**: P0 (필수, 비즈니스 규칙)

#### FR-6: 반복 인스턴스 생성 및 표시

- **설명**: 선택한 규칙에 따라 일정 인스턴스를 생성하고 캘린더에 표시
- **최대 생성 수**: 10,000회 (안전 한도)
- **우선순위**: P0 (필수)

#### FR-7: 반복 일정 수정 지원

- **설명**: 반복 일정의 원본 일정 정보 수정 (v1.0에서는 시리즈 전체 수정만 지원)
- **우선순위**: P1 (중요, 기본 수정 기능)

### 3.2 제외 범위 (Out of Scope v1.0)

#### 제외 사항

- **EX-1**: 단일 인스턴스만 수정 또는 이후만 적용 스코프 선택
- **EX-2**: 예외 날짜 지정 (특정 날짜만 스킵)
- **EX-3**: 개별 인스턴스 커스터마이징
- **EX-4**: 반복 일정 삭제 시 옵션 (전체 삭제 / 이후만 삭제)
- **EX-5**: 외부 캘린더 동기화 (Google Calendar, iCal 등)
- **EX-6**: 서버 동기화 및 충돌 해결
- **EX-7**: 반복 일정 공유 및 초대 기능
- **EX-8**: 반복 규칙 복잡한 패턴 (예: "매월 둘째 주 월요일")

**비고**: v1.0은 기본적인 반복 생성에 집중하며, 고급 편집 기능은 향후 버전에서 검토.

## 📐 4. 상세 기능 명세

### 4.1 데이터 모델

#### Event 타입 확장

```typescript
interface RepeatInfo {
  type: 'none' | 'daily' | 'weekly' | 'monthly' | 'yearly';
  interval: number; // 1-12, 기본값 1
  endDate?: string; // ISO 8601 (YYYY-MM-DD), count와 상호 배타적
  count?: number; // 1-1000, until과 상호 배타적
}

interface Event {
  id: string;
  title: string;
  date: string; // ISO 8601 (YYYY-MM-DD), KST 기준
  startTime: string; // HH:mm (00:00-23:59)
  endTime: string; // HH:mm
  description: string;
  location: string;
  category: string;
  repeat: RepeatInfo;
  notificationTime: number;
}
```

### 4.2 반복 유형별 생성 규칙

#### 4.2.1 Daily (매일)

```
앵커: startDate의 연-월-일
규칙: 매 interval일마다 동일 시간에 생성
시간: startTime-endTime 그대로 복사
예시:
  - startDate: 2025-11-01, interval: 1 → 매일 11/1, 11/2, 11/3, ...
  - startDate: 2025-11-01, interval: 2 → 11/1, 11/3, 11/5, ...
```

#### 4.2.2 Weekly (매주)

```
앵커: startDate의 요일 (0=일요일, 6=토요일)
규칙: 매 interval주마다 동일 요일에 생성
시간: startTime-endTime 그대로 복사
예시:
  - startDate: 2025-11-05(수), interval: 1 → 매주 수요일
  - startDate: 2025-11-05(수), interval: 2 → 격주 수요일
```

#### 4.2.3 Monthly (매월)

```
앵커: startDate의 일(day-of-month)
규칙: 매 interval개월 뒤 같은 "일"에 생성
제약: 존재하지 않는 날짜는 스킵 (대체 없음)
시간: startTime-endTime 그대로 복사

특수 케이스:
  - 31일 시작: 31일이 있는 달에만 생성
    2025-01-31, monthly → 1월, 3월, 5월, 7월, 8월, 10월, 12월만 생성
    2월, 4월, 6월, 9월, 11월은 스킵
  - 30일 시작: 30일이 없는 2월은 스킵
    2025-01-30, monthly → 2월은 스킵, 나머지 달은 생성
  - 29일 시작: 평년 2월은 스킵
    2025-01-29, monthly → 모든 달 생성 (2월도 29일 있음)
```

#### 4.2.4 Yearly (매년)

```
앵커: startDate의 월-일 (MM-DD)
규칙: 매 interval년 뒤 동일 월-일에 생성
제약: 윤년 2/29는 윤년에만 생성 (대체 없음)
시간: startTime-endTime 그대로 복사

특수 케이스:
  - 2월 29일 시작: 윤년에만 생성
    2024-02-29, yearly → 2024, 2028, 2032... (윤년에만)
    2025, 2026, 2027, 2029, 2030...는 스킵
  - 기타 날짜: 모든 해에 동일 월-일로 생성
    2025-03-15, yearly → 매년 3월 15일 생성
```

### 4.3 종료 조건 계산

#### 4.3.1 Count 기반 (횟수)

```
규칙: startDate 포함 총 count개 생성
예시:
  - startDate: 2025-11-01, count: 5 → 11/1, 11/2, 11/3, 11/4, 11/5 (5회)
  - startDate: 2025-01-31, monthly, count: 3 → 1/31, 3/31, 5/31 (3회, 2월/4월 스킵)
```

#### 4.3.2 Until 기반 (종료일)

```
규칙: startDate부터 until 날짜 "이하"에 해당하는 모든 인스턴스 생성
예시:
  - startDate: 2025-11-01, until: 2025-11-05, daily → 11/1~11/5 (5일)
  - startDate: 2024-02-29, yearly, until: 2030-02-28 → 2024, 2028만 생성 (윤년만)
```

#### 4.3.3 안전 한도

```
최대 생성 수: 10,000회
초과 시 에러: "반복 횟수가 너무 큽니다(최대 10,000)"
대응: 사용자에게 범위 축소 요청 (count 감소 또는 until 날짜 단축)
```

### 4.4 검증 규칙

#### 4.4.1 필수 필드

- `repeat.type !== 'none'`일 때:
  - `repeat.type` 필수 (none이면 안 됨)
  - `repeat.count` 또는 `repeat.endDate` 중 하나 필수

#### 4.4.2 상호 배타적 규칙

- `repeat.count`와 `repeat.endDate` 동시 지정 불가
- 둘 다 없으면 에러: "반복 종료 조건을 지정하세요"
- 둘 다 있으면 에러: "count와 until 중 하나만 지정하세요"

#### 4.4.3 값 범위

- `repeat.count`: 1-1000
- `repeat.interval`: 1-12
- `repeat.endDate`: startDate ≤ until ≤ startDate + 10년

#### 4.4.4 시간 검증

- `endTime <= startTime`인 경우: `endTime = startTime + 1시간`으로 자동 조정
- 경고 메시지: "종료 시간이 자동으로 1시간 뒤로 조정되었습니다"

## 🚨 5. 엣지 케이스 및 처리

### 5.1 날짜 특수 케이스

| #   | 케이스                    | 조건                          | 처리 방법                             | 우선순위 |
| --- | ------------------------- | ----------------------------- | ------------------------------------- | -------- |
| 1   | 월말 31일 + monthly       | startDate=31일, type=monthly  | 31일 있는 달에만 생성, 다른 달은 스킵 | P0       |
| 2   | 30일 + monthly (2월)      | startDate=30일, type=monthly  | 2월은 스킵                            | P0       |
| 3   | 윤년 2/29 + yearly        | startDate=02-29, type=yearly  | 윤년에만 생성, 평년 스킵              | P0       |
| 4   | 29일 + monthly (평년 2월) | startDate=01-29, type=monthly | 평년 2월도 29일 생성                  | P1       |
| 5   | 타임존 변경일             | 일광절약시간 등               | KST 기준으로 처리, 변경일 영향 없음   | P2       |

### 5.2 반복 규칙 케이스

| #   | 케이스                  | 조건                                  | 처리 방법                           | 우선순위 |
| --- | ----------------------- | ------------------------------------- | ----------------------------------- | -------- |
| 6   | count와 until 동시 지정 | repeat.count && repeat.endDate        | 에러 반환                           | P0       |
| 7   | 종료 조건 없음          | repeat.count 없고 repeat.endDate 없음 | 에러 반환                           | P0       |
| 8   | 매우 큰 반복 횟수       | 계산 결과 >10,000회                   | 에러 "반복 횟수가 너무 큽니다"      | P1       |
| 9   | interval > 1            | interval=2, 3 등                      | 규칙대로 계산 (매 2일/2주 등)       | P1       |
| 10  | 과거 날짜 시작          | startDate < 오늘                      | 정책에 따라 허용/차단 (현재는 허용) | P2       |

### 5.3 겹침 및 충돌 케이스

| #   | 케이스                     | 조건                            | 처리 방법                          | 우선순위 |
| --- | -------------------------- | ------------------------------- | ---------------------------------- | -------- |
| 11  | 반복 일정과 기존 일정 겹침 | 동일 시간대 다른 일정 존재      | **생성 강행, 경고 없음**           | P0       |
| 12  | 반복 일정 내부 겹침        | interval <1일이면서 시간대 겹침 | 정상 생성 (규칙대로)               | P1       |
| 13  | endTime ≤ startTime        | 사용자가 역전 시간 입력         | endTime = startTime + 1h 자동 조정 | P1       |

### 5.4 에러 처리

| 에러 코드              | 발생 조건                       | 사용자 메시지                                    | 내부 로그                         | 복구 방법                  |
| ---------------------- | ------------------------------- | ------------------------------------------------ | --------------------------------- | -------------------------- |
| `REPEAT_INVALID_SCOPE` | count와 until 동시 지정         | "count와 until 중 하나만 지정하세요"             | "repeat scope conflict"           | 하나만 남기고 재시도       |
| `REPEAT_MISSING_SCOPE` | count와 until 모두 누락         | "반복 종료 조건을 지정하세요"                    | "repeat scope missing"            | count 또는 until 입력 유도 |
| `REPEAT_TOO_MANY`      | 생성 상한 초과 (>10,000회)      | "반복 횟수가 너무 큽니다(최대 10,000)"           | "repeat expansion exceeded limit" | 범위 축소(기간/횟수 감소)  |
| `TIME_INVALID_RANGE`   | endTime ≤ startTime             | "종료 시간이 자동으로 1시간 뒤로 조정되었습니다" | "endTime auto adjusted (+1h)"     | 자동 조정 후 계속          |
| `DATE_INVALID_PAST`    | startDate가 과거 (정책 금지 시) | "과거 날짜는 선택할 수 없습니다"                 | "startDate in the past"           | 날짜 재선택                |

## 💡 6. 사용자 경험 (UX) 요구사항

### 6.1 UI 플로우

1. **일정 생성/수정 폼 열기**
2. **반복 설정 토글 활성화**
3. **반복 유형 선택** (드롭다운: 매일/매주/매월/매년)
4. **종료 조건 선택 및 입력**
   - 라디오 버튼: "횟수" 또는 "종료일"
   - 입력 필드 (count: 숫자, until: 날짜 선택기)
5. **고급 옵션** (선택): interval 설정
6. **미리보기** (선택): 예상 생성 일정 목록 표시
7. **저장**: 반복 일정 시리즈 생성

### 6.2 피드백 및 알림

- **성공**: "반복 일정이 생성되었습니다 (N개)"
- **경고**:
  - "종료 시간이 자동으로 1시간 뒤로 조정되었습니다"
  - "일부 날짜는 존재하지 않아 건너뛰었습니다 (N개 스킵)"
- **에러**:

- 2025-05-31 생성 ✓

## 🔄 9. 의존성 및 연관 기능

### 9.1 기술 의존성

- **날짜 유틸리티**: `dateUtils.ts`
  - `getDaysInMonth(year, month)`: 월의 일수 계산
  - `isLeapYear(year)`: 윤년 판단 (필요 시 구현)
- **시간 포맷팅**: ISO 8601 문자열 처리
- **이벤트 저장**: 기존 이벤트 저장 로직 확장 필요

### 9.2 기능 연관성

- **일정 겹침 검사 (`eventOverlap.ts`)**: 반복 일정에만 적용 안 함
- **이벤트 폼 (`useEventForm.ts`)**: 반복 설정 필드 추가 필요
- **캘린더 뷰**: 반복 일정 인스턴스 표시

## 📚 11. 용어 정의

| 용어                        | 정의                                       | 예시                             |
| --------------------------- | ------------------------------------------ | -------------------------------- |
| **인스턴스 (Instance)**     | 반복 규칙에 따라 생성된 개별 일정          | 2025-03-31 14:00-15:00           |
| **앵커 (Anchor)**           | 반복 계산의 기준이 되는 시작 날짜/요일     | startDate=2025-01-31             |
| **스킵 (Skip)**             | 존재하지 않는 날짜의 달/해는 생성하지 않음 | 2025-02-31, 2025-04-31           |
| **시리즈 (Series)**         | 동일한 반복 규칙을 가진 일정 그룹          | repeat.id로 연결                 |
| **종료 조건 (Termination)** | 반복을 종료하는 조건 (count 또는 until)    | count=5 또는 until=2026-12-31    |
| **간격 (Interval)**         | 반복 주기의 간격                           | interval=2 → 2일마다, 2주마다 등 |
