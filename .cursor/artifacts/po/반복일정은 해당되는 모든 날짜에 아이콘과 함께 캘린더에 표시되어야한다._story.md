# User Story: 반복일정은 해당되는 모든 날짜에 아이콘과 함께 캘린더에 표시되어야한다.

## Story
반복 규칙으로 저장된 일정을 한눈에 구분하고 싶다. 캘린더에서 해당되는 모든 날짜에 반복 일정이 표시되고, 반복임을 나타내는 아이콘이 함께 보이면 빠르게 식별할 수 있다.

## As / I want / So that
- As: 캘린더를 사용하는 사용자
- I want: 반복일정이 해당되는 모든 날짜에 표시되고 반복 아이콘으로 식별되길 원한다
- So that: 단일 일정과 반복 일정을 빠르게 구분하고 일정 계획을 효율적으로 수립할 수 있다

## Acceptance Criteria
1) 월/주/일 보기 공통
- 보이는 기간 내 반복 규칙에 따라 생성되는 모든 인스턴스가 렌더링된다.
- 각 인스턴스에는 반복 아이콘(🔁 또는 프로젝트 제공 SVG)이 함께 표시된다.
- 아이콘에는 `aria-label="반복 일정"` 접근성 라벨이 제공된다.

2) 규칙 및 예외 처리
- repeatEnd 이후 인스턴스는 표시되지 않는다(당일 포함 규칙 준수).
- exceptions 목록에 포함된 날짜는 표시되지 않는다.
- interval, 요일 세트, 월 N번째 요일 등 일반적인 반복 규칙이 적용된다.

3) 상호 운용성
- 단일 이벤트와 반복 이벤트가 같은 날에 있어도 모두 표시된다.
- 뷰 이동/전환 시 가시 기간에 맞춰 인스턴스와 아이콘이 갱신된다.

## Non-Functional
- 로컬 데이터 기준 뷰 전환 시 100ms 내 연산 목표
- 기본 타임존 기준 계산

## Out of Scope
- 개별 인스턴스 편집(예외 인스턴스 수정 UI)
- 반복 규칙 생성/수정 UX 변경

## Tasks
- 반복 인스턴스 생성 로직 확인 및 확장(필요 시)
- 인스턴스 데이터에 `isRecurring` 플래그 추가 또는 파생
- 이벤트 렌더러에 반복 아이콘 조건부 렌더링 추가
- 접근성 라벨 및 툴팁(선택) 추가
- 테스트(weekly/monthly/예외/종료일/접근성) 작성
