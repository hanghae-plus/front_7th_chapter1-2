# Step: 스프린트 계획 문서 작성

```xml
<step>
  <purpose>
    정의한 스프린트 목표와 마일스톤을 문서로 작성하여 저장합니다.
  </purpose>

  <how-to>
    <action n="1">
      <do>템플릿 확인</do>
      <detail>
        templates/scrum/sprint-plan.md.hbs 템플릿을 확인하여 필수 섹션과 형식을 파악합니다.
      </detail>
    </action>

    <action n="2">
      <do>필수 섹션 작성</do>
      <detail>
        다음 섹션들을 작성합니다:
        - 헤더: 기능명, 작성일
        - 스프린트 목표: 구체적이고 측정 가능한 목표
        - 마일스톤: "누가 무엇을 한다" 형식의 마일스톤 목록
        - 작업 목록 (선택사항): 구체적인 작업 항목
      </detail>
    </action>

    <action n="3">
      <do>문서 저장</do>
      <detail>
        작성한 스프린트 계획을 지정된 경로와 파일명 규칙에 따라 저장합니다.
      </detail>
    </action>
  </how-to>

  <constraints>
    <constraint>템플릿 양식을 반드시 따를 것</constraint>
    <constraint>모든 필수 섹션을 포함할 것</constraint>
    <constraint>내용이 구체적이고 명확해야 함</constraint>
  </constraints>

  <success-criteria>
    <criterion>필수 섹션이 모두 포함됨</criterion>
    <criterion>템플릿 양식을 준수함</criterion>
    <criterion>내용이 구체적이고 명확함</criterion>
  </success-criteria>
</step>
```
