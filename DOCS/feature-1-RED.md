# [RED] Feature 1: 반복 유형 선택 - 단일 책임 테스트 작성

## 관련 요구사항

- 1. 반복 유형 선택 (recurring type selection)
  - 일정 생성/수정 시 다음 반복 유형 중 하나를 선택할 수 있다: 매일, 매주, 매월, 매년
  - 31일 선택 시: 매월 31일에만 일정 생성(30/28/29일 대체 금지)
  - 2/29 선택 시: 윤년 2월 29일에만 일정 생성
  - 반복 일정은 겹침 허용

## 산출 목적

- 위 요구사항에 대응하는 핵심 “반복 유형 선택” 동작에 대한 실패 테스트(RED) 작성을 목표로 한다.
- 일정 생성 시, 반복 유형이 정상 인식 및 처리되는지 검증
- 특수 규칙(31일, 2/29일, 겹침 허용)에 대한 단일 책임 테스트 작성

## 테스트 작성 전략

- src/**tests**/hooks/ 또는 unit/util에 테스트 파일 추가
- 테스트명: “[유틸/훅명]은 [조건]일 때 [결과동작]해야 한다”
- 예시 1: generateRecurrences 함수는 매월 31일 반복 선택 시 31일에만 생성한다
- 예시 2: generateRecurrences 함수는 연 2/29 반복 선택 시 윤년에만 생성한다

## 검증 범위 및 예시

- 매월 31일 반복: 1~12월 전부 시도 → 1, 3, 5, 7, 8, 10, 12월 31일만 발생
- 연 2/29 반복: 2024~2030년 모두 시도 → 2024, 2028년에만 생성(그 외 X)
- 반복 일정이 기존 일정과 겹쳐도 생성됨.
