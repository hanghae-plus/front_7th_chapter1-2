# PRD: 반복 일정 기능 (확정)

- 버전: v1.2.0

## 1. 배경과 문제 정의

캘린더 사용자는 회의/기념일/결제일 등 반복되는 일정을 손쉽게 생성·표시·수정·삭제하길 원한다. 기존에는 엣지 케이스(매월 31일, 윤년 2/29) 처리와 단일/전체 수정·삭제 분기가 모호해 사용자 혼란과 운영 이슈가 있었다. 본 PRD는 반복 유형·표시·종료 조건·수정/삭제 동작을 명확히 정의한다.

## 2. 목표와 성공 지표

- 반복 일정의 생성/표시/수정/삭제 동작을 오해 없이 일관되게 제공
- 성공 지표
  - 반복 일정 플로우 완료율 ≥ 99%
  - 반복 아이콘 표시 및 엣지 케이스 반영 정확도 ≥ 99%
  - 관련 CS 비율 월간 50% 이상 감소

## 3. 범위

### 포함 범위

- 반복 유형 선택: 일정 생성 또는 수정 시 반복 유형 지정(매일/매주/매월/매년)
- 예외 규칙(필수)
  - 매월 31일 선택 시: 31일이 있는 달에만 생성. 마지막 날로 치환하지 않음.
  - 매년 2/29(윤년) 선택 시: 2/29에만 생성. 비윤년에는 생성하지 않음.
- 겹침 정책: 반복일정은 일정 겹침을 고려하지 않음(중복 허용).
- 표시: 캘린더 뷰에서 반복 인스턴스에 반복 아이콘 표시로 구분.
- 반복 종료: 특정 날짜까지 설정 가능. 최대 종료일은 2025-12-31.
- 반복 일정 수정
  - 단일 수정: 확인 텍스트에서 ‘예’를 선택 시 해당 인스턴스만 단일 일정으로 변경. 반복 아이콘 제거.
  - 전체 수정: 확인 텍스트에서 ‘아니오’를 선택 시 시리즈 전체에 적용. 반복 아이콘 유지.
- 반복 일정 삭제
  - 단일 삭제: 확인 텍스트에서 ‘예’를 선택 시 해당 인스턴스만 삭제.
  - 전체 삭제: 확인 텍스트에서 ‘아니오’를 선택 시 시리즈 전체 삭제.

### 제외 범위

- 외부 캘린더 연동/동기화
- 모바일 전용 리디자인 및 대규모 UI 개편

## 4. UX/카피(확정)

- 반복 유형 선택 옵션: “반복 안 함 / 매일 / 매주 / 매월 / 매년”
- 반복 종료: “반복 종료”, 옵션: “특정 날짜까지” (날짜 피커, 최대 2025-12-31)
- 반복 표시: 반복 인스턴스에 반복 아이콘(예: ∞ 또는 ↻ 유사) 노출
- 단일/전체 분기 확인 카피
  - 수정 시: “해당 일정만 수정하시겠어요?”
    - 버튼: “예(단일 수정)”, “아니오(전체 수정)”
  - 삭제 시: “해당 일정만 삭제하시겠어요?”
    - 버튼: “예(해당 일정만 삭제)”, “아니오(전체 삭제)”
- 단일 수정 결과: 해당 인스턴스는 시리즈에서 분리되어 일반 일정으로 전환되고 반복 아이콘이 사라짐

## 5. 기능 요구사항(상세)

- 반복 유형
  - 매일: 시작일을 기준으로 매일 생성
  - 매주: 시작요일을 기준으로 매주 동일 요일에 생성
  - 매월: 시작일의 일(day)을 기준으로 매월 생성하되, 31일 규칙 적용
  - 매년: 시작일의 월/일을 기준으로 매년 생성하되, 2/29 규칙 적용
- 예외 규칙(중요)
  - 매월 31일: 31일이 없는 달에는 해당 인스턴스를 생성하지 않음(말일 치환 금지)
  - 매년 2/29: 윤년에만 생성. 비윤년에는 생성하지 않음
- 겹침 정책: 다른 일정과의 중복 여부와 무관하게 반복 인스턴스 생성 및 표시
- 표시: 반복 인스턴스에 반복 아이콘 노출. 단일 수정으로 분리된 일정은 아이콘 제거
- 종료 조건: 특정 종료일 포함 생성. 종료일을 초과하는 인스턴스는 생성하지 않음(최대 2025-12-31)
- 수정/삭제 분기
  - 수정
    - 예(단일): 해당 인스턴스를 단일 일정으로 분리 후 변경사항 적용. 시리즈와의 연결 해제, 아이콘 제거
    - 아니오(전체): 반복 마스터 규칙을 갱신하고 뷰 범위 내 인스턴스를 재계산
  - 삭제
    - 예(단일): 해당 인스턴스만 삭제
    - 아니오(전체): 시리즈 전체 삭제

## 6. 비기능 요구사항

- 월간 뷰 기준 내부 계산으로 반복 인스턴스 표시 p95 ≤ 300ms
- 확인 다이얼로그는 버튼 라벨과 결과 동작이 1:1로 매칭되어 오동작을 방지

## 7. 데이터/설계 고려사항

- 데이터 모델(예시)
  - EventSeries(마스터): id, title, startDate, timeRange, recurrenceRule(type, interval?, until), exceptions?
  - EventInstance(파생): id, seriesId, date, isDetached(boolean), overriddenFields?
- 생성 전략
  - 뷰포트(월/주/일) 범위 내에서만 인스턴스 계산(지연 생성)
  - 31일/2월29일 규칙은 인스턴스 생성 전 필터링
- 수정/삭제
  - 단일: 대상 인스턴스를 분리(detach)하여 단일 이벤트로 저장, 아이콘 제거
  - 전체: 시리즈의 recurrenceRule 갱신 후 표시 구간 재계산
- 표시
  - series에 연결된 인스턴스만 반복 아이콘 표시, 분리되면 제거

## 8. 검증 기준(수용 테스트)

- 반복 유형 선택
  - 매일/매주/매월/매년 각각 생성 시 정상 생성됨
  - 매월 31일: 4/6/9/11/2월에는 생성되지 않음
  - 매년 2/29: 2024/2028에는 생성, 2025/2026/2027에는 미생성
- 표시
  - 반복 인스턴스에 반복 아이콘이 노출됨
  - 단일 수정으로 분리된 일정은 아이콘이 사라짐
- 종료 조건
  - 종료일 설정 시 종료일 이후 인스턴스는 생성되지 않음
  - 종료일은 최대 2025-12-31을 초과하여 설정할 수 없음
- 수정
  - “해당 일정만 수정하시겠어요?”에서 예 선택 시 단일 전환 및 아이콘 제거
  - 동일 확인에서 아니오 선택 시 시리즈 전체에 변경사항 반영, 아이콘 유지
- 삭제
  - “해당 일정만 삭제하시겠어요?”에서 예 선택 시 해당 인스턴스만 삭제
  - 동일 확인에서 아니오 선택 시 시리즈 전체 삭제

## 9. 추적 지표

- 반복 생성/수정/삭제 플로우 완료율
- 단일/전체 분기 선택 비율 및 취소율
- 반복 아이콘 표시 오류율
