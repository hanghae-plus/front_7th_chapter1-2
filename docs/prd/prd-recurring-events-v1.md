# PRD: 반복 일정 기능

- 버전: v1

## 1. 배경과 문제 정의

현재 일정 관리 시스템에서 반복되는 일정을 매번 수동으로 생성해야 하는 불편함이 있습니다. 사용자가 매일, 매주, 매월, 매년 반복되는 일정을 한 번에 설정하고 관리할 수 있는 기능을 추가하여 사용자 편의성을 향상시킵니다.

## 2. 목표

- 반복 일정 생성 기능 추가
- 반복 일정 수정 기능 추가 (단일/전체 선택)
- 반복 일정 삭제 기능 추가 (단일/전체 선택)
- 반복 일정 시각적 표시

## 3. 범위

### 포함 범위

- 반복 유형 선택 UI (매일, 매주, 매월, 매년)
- 반복 종료 조건 설정 (특정 날짜까지 - 선택 사항)
- 반복 일정 아이콘 표시
- 반복 일정 수정 시 단일/전체 선택 다이얼로그
- 반복 일정 삭제 시 단일/전체 선택 다이얼로그
- 특수 날짜 처리 (31일 매월, 윤년 29일 매년)

### 제외 범위

- 반복 일정 겹침 검사
- 특정 요일 선택 기능 (예: 매주 월요일과 수요일만)
- 복잡한 반복 패턴 (예: 매월 마지막 금요일)
- 반복 예외 설정 (특정 날짜 제외)

## 4. 사용자 시나리오

### 사용자 시나리오

- 사용자는 일정 생성 시 "반복 일정" 체크박스를 선택할 수 있다
- 사용자는 일정 수정 시 "반복 일정" 체크박스를 선택할 수 있다
- "반복 일정" 체크박스를 선택하면 반복 설정 UI가 표시된다
- 사용자는 반복 유형 드롭다운에서 "매일", "매주", "매월", "매년" 중 하나를 선택할 수 있다
- 사용자는 반복 간격을 숫자로 입력할 수 있다
- 반복 간격 입력 필드의 기본값은 1이다
- 반복 간격 입력 필드의 최소값은 1이다
- 사용자는 반복 종료일을 선택할 수 있다
- 반복 종료일은 선택 사항이며, 선택하지 않으면 2025년 12월 31일까지 반복된다
- 반복 종료일을 선택하는 경우 2025년 12월 31일을 초과할 수 없다
- 반복 종료일을 선택하는 경우 일정 시작일 이후 날짜여야 한다
- 31일에 "매월" 반복을 선택하면 31일이 있는 달에만 일정이 생성된다
- 31일이 없는 달은 2월, 4월, 6월, 9월, 11월이다
- 윤년 2월 29일에 "매년" 반복을 선택하면 윤년에만 일정이 생성된다
- 반복 일정은 일정 겹침 검사를 하지 않는다
- 사용자는 일정 추가 버튼을 클릭하여 반복 일정을 생성할 수 있다
- 반복 일정이 생성되면 반복 종료일까지 모든 일정이 서버에서 생성된다
- 캘린더의 주간 뷰에서 반복 일정에 반복 아이콘이 표시된다
- 캘린더의 월간 뷰에서 반복 일정에 반복 아이콘이 표시된다
- 일정 목록에서 반복 일정에 반복 아이콘이 표시된다
- 일정 목록에서 반복 정보가 텍스트로 표시된다
- 반복 정보 텍스트는 "반복: N일마다" 형식으로 표시된다
- 반복 정보 텍스트는 "반복: N주마다" 형식으로 표시된다
- 반복 정보 텍스트는 "반복: N월마다" 형식으로 표시된다
- 반복 정보 텍스트는 "반복: N년마다" 형식으로 표시된다
- 반복 종료일이 설정된 경우 "(종료: YYYY-MM-DD)" 형식으로 추가 표시된다
- 사용자가 반복 일정의 수정 버튼을 클릭하면 "반복 일정 수정" 다이얼로그가 표시된다
- "반복 일정 수정" 다이얼로그에는 "해당 일정만 수정하시겠어요?" 텍스트가 표시된다
- "반복 일정 수정" 다이얼로그에는 "예" 버튼과 "아니오" 버튼이 있다
- "반복 일정 수정" 다이얼로그에서 "예" 버튼을 클릭하면 해당 일정만 수정 모드로 전환된다
- 단일 일정 수정 모드에서 일정을 수정하면 해당 일정만 수정된다
- 단일 일정 수정 시 수정된 일정의 반복 타입이 'none'으로 변경된다
- 단일 일정 수정 후 해당 일정의 반복 아이콘이 사라진다
- "반복 일정 수정" 다이얼로그에서 "아니오" 버튼을 클릭하면 전체 일정 수정 모드로 전환된다
- 전체 일정 수정 모드에서 일정을 수정하면 같은 반복 그룹의 모든 일정이 수정된다
- 전체 일정 수정 시 반복 정보가 유지된다
- 전체 일정 수정 후 반복 아이콘이 유지된다
- 사용자가 반복 일정의 삭제 버튼을 클릭하면 "반복 일정 삭제" 다이얼로그가 표시된다
- "반복 일정 삭제" 다이얼로그에는 "해당 일정만 삭제하시겠어요?" 텍스트가 표시된다
- "반복 일정 삭제" 다이얼로그에는 "예" 버튼과 "아니오" 버튼이 있다
- "반복 일정 삭제" 다이얼로그에서 "예" 버튼을 클릭하면 해당 일정만 삭제된다
- 단일 일정 삭제 시 같은 반복 그룹의 다른 일정들은 유지된다
- "반복 일정 삭제" 다이얼로그에서 "아니오" 버튼을 클릭하면 전체 일정이 삭제된다
- 전체 일정 삭제 시 같은 반복 그룹의 모든 일정이 삭제된다
