# PRD: 반복 일정 기능

- 버전: v2

## 1. 배경과 문제 정의

현재 캘린더 애플리케이션에는 일정 생성, 수정, 삭제 기능이 구현되어 있으나 반복 일정 기능이 주석 처리되어 비활성화되어 있습니다. 사용자가 매일, 매주, 매월, 매년 반복되는 일정을 효과적으로 관리할 수 있도록 반복 일정 기능을 활성화하고 완성해야 합니다.

## 2. 목표

- 반복 일정 생성 기능 구현
- 반복 일정 표시 기능 구현
- 반복 일정 수정 기능 구현 (단일/전체 선택)
- 반복 일정 삭제 기능 구현 (단일/전체 선택)

## 3. 범위

### 포함 범위

- 반복 유형 선택 UI (매일, 매주, 매월, 매년)
- 반복 간격 설정 UI
- 반복 종료일 설정 UI
- 반복 일정 생성 로직 (특정 날짜 규칙 적용)
- 캘린더 뷰에서 반복 일정 아이콘 표시
- 일정 목록에서 반복 일정 아이콘 표시
- 반복 일정 수정 시 단일/전체 선택 다이얼로그
- 반복 일정 삭제 시 단일/전체 선택 다이얼로그

### 제외 범위

- 반복 일정의 일정 겹침 검사
- 반복 종료 조건 중 "횟수 지정" 옵션
- 요일 선택 기능 (매주 반복 시 특정 요일만 선택)
- 월 반복 시 "매월 첫째 주 월요일" 같은 상대적 날짜 지정

## 4. 사용자 시나리오

### 사용자 시나리오

- 사용자는 일정 생성 폼에서 "반복 일정" 체크박스를 체크할 수 있다.
- 사용자가 "반복 일정" 체크박스를 체크하면 반복 유형 선택 드롭다운이 화면에 표시된다.
- 사용자는 반복 유형 드롭다운에서 "매일", "매주", "매월", "매년" 중 하나를 선택할 수 있다.
- 사용자는 반복 간격 입력 필드에 1 이상의 숫자를 입력할 수 있다.
- 반복 간격 입력 필드의 기본값은 1이다.
- 사용자는 반복 종료일 입력 필드에 날짜를 선택할 수 있다.
- 반복 종료일 필드가 비어있으면 시스템은 2025-12-31을 반복 종료일로 설정한다.
- 반복 종료일의 최대값은 2025-12-31이다.
- 사용자가 31일에 매월 반복 일정을 생성하면 시스템은 31일이 있는 달에만 일정을 생성한다.
- 사용자가 윤년 2월 29일에 매년 반복 일정을 생성하면 시스템은 2월 29일이 있는 해에만 일정을 생성한다.
- 시스템은 반복 일정 생성 시 일정 겹침 검사를 수행하지 않는다.
- 캘린더의 주간 뷰에서 반복 일정은 반복 아이콘과 함께 표시된다.
- 캘린더의 월간 뷰에서 반복 일정은 반복 아이콘과 함께 표시된다.
- 일정 목록에서 반복 일정은 반복 아이콘과 함께 표시된다.
- 사용자가 반복 일정의 수정 버튼을 클릭하면 "해당 일정만 수정하시겠어요?" 텍스트가 포함된 확인 다이얼로그가 표시된다.
- 확인 다이얼로그에는 "예" 버튼과 "아니오" 버튼이 표시된다.
- 사용자가 반복 일정 수정 다이얼로그에서 "예" 버튼을 클릭하면 일정 수정 폼이 해당 일정의 정보로 채워진다.
- 사용자가 반복 일정을 단일 수정하여 저장하면 해당 일정의 반복 유형이 'none'으로 변경된다.
- 단일 수정된 일정은 반복 아이콘이 표시되지 않는다.
- 사용자가 반복 일정 수정 다이얼로그에서 "아니오" 버튼을 클릭하면 일정 수정 폼이 해당 일정의 정보로 채워진다.
- 사용자가 반복 일정을 전체 수정하여 저장하면 동일한 반복 그룹의 모든 일정이 수정된다.
- 전체 수정된 일정들은 반복 유형과 반복 아이콘이 유지된다.
- 사용자가 반복 일정의 삭제 버튼을 클릭하면 "해당 일정만 삭제하시겠어요?" 텍스트가 포함된 확인 다이얼로그가 표시된다.
- 삭제 확인 다이얼로그에는 "예" 버튼과 "아니오" 버튼이 표시된다.
- 사용자가 반복 일정 삭제 다이얼로그에서 "예" 버튼을 클릭하면 해당 일정만 삭제된다.
- 사용자가 반복 일정 삭제 다이얼로그에서 "아니오" 버튼을 클릭하면 동일한 반복 그룹의 모든 일정이 삭제된다.
