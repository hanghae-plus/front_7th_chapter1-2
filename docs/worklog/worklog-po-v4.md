# 업무 과정

## 1. 현재 구현 범위 파악

- 기존 PRD v3 검토
- `expandRecurringEvents` 함수 코드 분석 (src/utils/recurringUtils.ts, 334-396 라인)
- 이미 구현되어 있지만 PRD에 명시되지 않은 기능 발견:
  - 시작일이 뷰 범위보다 이전인 경우, 뷰 범위 내 첫 반복 날짜부터 전개
  - `if (currentDate < rangeStartStr)` 조건으로 처리
  - 무한 반복 일정도 현재 뷰 범위 내에서 올바르게 전개됨

## 2. 요구사항 구체화

사용자 요청: "선택된 달보다 이른 날짜에 등록된 반복일정도 캘린더와 일정목록에 표시되어야 한다"

구체화된 요구사항:
- 반복 일정의 시작일이 현재 뷰 범위보다 이전이어도 현재 뷰에 표시되어야 함
- 예시 시나리오:
  - 10월 3일 시작 매일 반복 → 11월 캘린더에도 표시
  - 9월 15일 시작 매주 반복 → 10월 주간 뷰에도 표시
- 뷰 범위 내 첫 반복 날짜부터 전개
- 무한 반복 일정은 항상 현재 뷰 범위 내에서 전개
- 종료일이 있는 경우 종료일까지만 전개
- 예외 케이스:
  - 반복 시작일이 뷰 범위 이후 → 표시 안 함
  - 반복 종료일이 뷰 범위 이전 → 표시 안 함

- 포함 범위에 "과거에 시작된 반복 일정의 뷰 범위 내 인스턴스 자동 전개" 추가

## 4. 변경사항 요약

**추가된 요구사항:**
- 선택된 달/주보다 이른 날짜에 생성된 반복 일정도 현재 뷰에 표시
- 반복 일정의 시작일이 뷰 범위보다 이전인 경우, 뷰 범위 내 첫 반복 날짜부터 전개
- 무한 반복 일정은 항상 현재 뷰 범위 내에서 전개되어 표시
- 종료일이 설정된 반복 일정은 종료일까지만 전개되어 표시
- 반복 일정의 시작일이 뷰 범위 이후인 경우 표시되지 않음
- 반복 일정의 종료일이 뷰 범위 이전인 경우 표시되지 않음
