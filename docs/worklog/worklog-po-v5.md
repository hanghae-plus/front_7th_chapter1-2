# 다음 작업자에게 남기는 코멘트

반복 일정 수정 UX를 개선하기 위해 다이얼로그 표시 시점을 변경했습니다. 주요 변경사항:

1. **수정 버튼 클릭 시점에 다이얼로그 표시**: 기존에는 폼 제출 시 다이얼로그가 나타났지만, 이제는 Edit 버튼 클릭 시 즉시 표시됩니다.

2. **폼 상태 자동 설정**: 다이얼로그에서 "예"(단일 수정)를 선택하면 반복 일정 체크박스가 자동으로 해제되고, "아니오"(전체 수정)를 선택하면 체크박스가 유지됩니다.

3. **구현 시 주의사항**:

   - `editEvent` 함수를 호출할 때 반복 일정 여부에 따라 `isRepeating` state 설정 필요
   - `addOrUpdateEvent`에서 기존의 다이얼로그 로직 제거 (202-207번 줄)
   - Edit 버튼 onClick 핸들러에 다이얼로그 로직 추가
   - `splitRecurringEvent` 함수가 이미 구현되어 있으므로 이를 활용

4. **테스트 케이스 업데이트 필요**:
   - 기존 테스트가 폼 제출 후 다이얼로그를 기대하므로 수정 필요
   - Edit 버튼 클릭 후 다이얼로그가 나타나는지 확인하는 테스트로 변경

테스트 우선 개발 방식으로 진행하시면 좋을 것 같습니다.
