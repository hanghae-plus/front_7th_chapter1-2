## 2. 수용 기준 추출

PRD v4 "반복 일정 뷰 범위 표시"에서 추출한 수용 기준:

1. 선택된 달/주보다 이른 날짜에 생성된 반복 일정도 현재 뷰에 표시
2. 반복 일정의 시작일이 뷰 범위보다 이전인 경우, 뷰 범위 내 첫 반복 날짜부터 전개
3. 무한 반복 일정은 항상 현재 뷰 범위 내에서 전개되어 표시
4. 종료일이 설정된 반복 일정은 종료일까지만 전개되어 표시
5. 반복 일정의 시작일이 뷰 범위 이후인 경우 표시되지 않음
6. 반복 일정의 종료일이 뷰 범위 이전인 경우 표시되지 않음

## 3. 경계값 및 예외 시나리오 정의

### 정상 케이스
- 10월 시작 → 11월로 이동 (매일/매주/매월 반복)
- 무한 반복 일정의 여러 달 이동

### 경계값 케이스
- 반복 시작일 = 뷰 범위 시작일
- 반복 종료일 = 뷰 범위 종료일
- 반복 시작일이 여러 달 이전 (예: 8월 시작 → 11월 뷰)
- 매월 31일 반복 시 달 이동 (31일 없는 달 건너뛰기)

### 예외 케이스
- 반복 종료일 < 뷰 범위 시작일 (표시 안 됨)
- 반복 시작일 > 뷰 범위 종료일 (표시 안 됨)
- 뷰를 시작일보다 이전으로 이동 (표시 안 됨)

### 뷰 타입별 시나리오
- 월간 뷰에서 달 이동
- 주간 뷰에서 주 이동
