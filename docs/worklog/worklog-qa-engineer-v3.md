Test First Engineer님께,

PRD v5의 주요 변경사항을 테스트 케이스에 반영했습니다. 핵심 변경사항:

## 변경된 사용자 플로우

**기존 (v4)**:

```
Edit 버튼 클릭 → 폼 표시 → 수정 → 제출 → 다이얼로그
```

**변경 (v5)**:

```
Edit 버튼 클릭 → 다이얼로그 → 폼 표시(자동 설정) → 수정 → 제출
```

## 테스트 코드 작성 시 주의사항

1. **시나리오 8 (단일 인스턴스 수정)**:

   - Edit 버튼 클릭 후 즉시 다이얼로그가 나타나는지 확인
   - "예" 버튼 클릭 후 폼의 '반복 일정' 체크박스가 해제되어 있는지 확인
   - 반복 설정 UI가 숨겨져 있는지 확인
   - 폼 제출 시 추가 다이얼로그가 나타나지 않는지 확인

2. **시나리오 9 (전체 수정)**:

   - "아니오" 버튼 클릭 후 폼의 '반복 일정' 체크박스가 선택되어 있는지 확인
   - 반복 설정 UI가 표시되고 기존 값이 채워져 있는지 확인

3. **시나리오 9-1 (일반 일정 수정)**:

   - Edit 버튼 클릭 후 다이얼로그 없이 바로 폼이 나타나는지 확인
   - '반복 일정' 체크박스가 해제되어 있는지 확인

4. **구현 위치**:
   - `App.tsx`의 Edit 버튼 onClick 핸들러 수정
   - `isRecurringEditDialogOpen` state 활용
   - `editEvent` 함수 호출 시 `isRepeating` 파라미터 전달
   - `addOrUpdateEvent`에서 기존 다이얼로그 로직 제거

기존 테스트 코드가 실패할 예정이니, 이 문서를 참고하여 테스트 코드를 수정해주세요.
