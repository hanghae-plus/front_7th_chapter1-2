# Sprint Plan: Recurring Events v1

- 버전: v1.0.0

## 목표

반복 유형(매일/매주/매월/매년) 생성·표시·수정·삭제의 일관된 UX 제공. 엣지 규칙(매월 31일, 윤년 2/29) 및 종료일(≤ 2025-12-31) 정확 반영. 단일/전체 분기 UX(확인 카피) 명확화 및 아이콘 표시 일관성 보장.

## 마일스톤

- PO가 반복 일정 PRD를 확정한다
- FE와 PO가 설계안을 정리하고 프로토타입을 제출한다
- FE가 반복 생성/표시/종료/분기 처리를 구현한다
- QA가 테스트를 완료하고 릴리스를 진행한다

## 작업 목록

- 반복 유형 선택 UI 컴포넌트 구현 (3pt)
- 반복 규칙 엔진: 매일/매주/매월/매년 + 31일/2월29일 규칙 (5pt)
- 종료 조건 로직(특정 날짜까지, ≤ 2025-12-31) (2pt)
- 캘린더 뷰 아이콘 표시 및 스타일 (2pt)
- 단일/전체 수정 분기: 분리(detach)/마스터 갱신 (5pt)
- 단일/전체 삭제 분기: 인스턴스 삭제/시리즈 삭제 (3pt)
- 수용 테스트/단위·통합 테스트 작성 (4pt)
- 성능 검증(p95 ≤ 300ms) 및 최적화 (2pt)
